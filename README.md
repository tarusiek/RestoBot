# Restaurant Bot

AI-powered restaurant lead generation and outreach pipeline.

## Features

- Google Maps scraping
- Website discovery
- Instagram discovery
- Website analysis
- Branding analysis
- AI-generated outreach
- Automated lead qualification
- Outreach automation

## Folder Structure

- `/data/raw` → raw scraped data
- `/data/processed` → analyzed leads
- `/data/screenshots` → website screenshots
- `/data/exports` → final exports
- `/scripts/scraper` → scraping logic
- `/scripts/analyzer` → website analysis
- `/scripts/enrichment` → email/social enrichment
- `/scripts/messaging` → AI-generated messages
- `/scripts/outreach` → sending automation
